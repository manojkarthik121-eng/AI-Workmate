# AI Workmate — First Tester Guide

Thanks for trying AI Workmate! This is an early version of a personal AI workspace that turns rough notes into an organised plan.

## What to try

1. Download the project ZIP and extract it.
2. Make sure the project files stay together in the same folder.
3. Install Python 3.8 or newer if needed.
4. Double-click `Start_AI_Workmate.bat`.
5. When prompted, enter your own Gemini API key. The input is hidden; the launcher does not save the key.
6. Try organising some everyday notes (avoid sensitive or confidential information).
7. Explore the generated summary and tasks. Try checking off tasks, editing them, and saving/returning to a session.
8. When finished, press Ctrl+C in the launcher window to stop the local server.

## Privacy and safety

- AI Workmate runs locally on your computer, but note text you submit for AI organisation is sent to Google's Gemini API.
- Use your own Gemini API key. Do not share it.
- Don't enter passwords, payment details, government identifiers, confidential work information, or other sensitive data.
- Saved sessions stay in your browser's local storage on that device/profile. Exported backups may contain your notes; keep them private.
- This is an early local-run project, not a hosted service. Don't expose it to the public internet.
